# Maya Phaselock

An implementation of the Phaselock skill Maya has in BL2 - the unreal script side is entirely
AI-generated. Just pointed it at some stub files and look at it go. This script is just a proof of
concept, not an actual skill.

To use this mod all you need to do is copy the phaselock python sdk mod to your sdk_mods folder
when enabled lilith's Phasewalk will be replaced with Phaselock.
